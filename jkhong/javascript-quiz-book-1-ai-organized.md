## 프런트엔드 레벨을 높이는 자바스크립트 퀴즈북 1장

### 1\. 원시 타입과 객체 타입

|   구분   |                                  원시 타입 (Primitive Type)                                  |                          객체 타입 (Object Type)                           |
| :------: | :------------------------------------------------------------------------------------------: | :------------------------------------------------------------------------: |
| **타입** |                 String, Number, Boolean, Symbol, BigInt, **Null, Undefined**                 | 함수(Function), 배열(Array), 정규식(RegExp), Date 등 원시를 제외한 모든 것 |
| **저장** |                        **값 자체가 메모리**에 직접 저장 (**불변함**)                         |   \*\*객체의 메모리 주소(참조, Reference)\*\*가 변수에 저장 (**가변적**)   |
| **특징** | Null/Undefined를 제외하고 **래퍼 객체**를 가짐. Null/Undefined에 메서드 사용 시 `TypeError`. |  수정 가능한 다양한 속성을 가진 자료구조. 키는 문자열 또는 Symbol만 허용.  |

### 2\. 타입 및 값의 상세 이해

#### 2.1. Number 타입 (64비트 배정밀도 부동 소수점)

자바스크립트 `Number` 타입은 **IEEE 754 64비트 배정밀도 부동 소수점 방식**을 사용합니다.

- **구조:** 1비트 **부호부**, 11비트 **지수부** (Bias: 1023), 52비트 **가수부** (Hidden Bit 포함 **$53$비트 정밀도**).
- **원리:** 숫자를 $1.xxxx \times 2^{n}$ 형태로 표현합니다. 지수부를 통해 표현 **범위**가 넓어지는 대신, 가수부의 52비트 한계로 $15$자리를 초과하는 10진수에서 \*\*정밀도 손실(오차)\*\*이 발생할 수 있습니다.
- **안전 정수 범위:** **`Number.MAX_SAFE_INTEGER`** ($2^{53}-1$)까지는 정확도를 보장하며, 이를 초과하는 정수 연산 시 오차로 인해 `N + 1 === N + 2`가 \*\*`true`\*\*가 될 수 있습니다.

#### 2.2. BigInt 타입

- `Number` 타입의 안전 범위를 초과하는 **모든 크기의 정수**를 정확하게 표현하기 위해 ES2020에 추가된 원시 타입입니다.
- 숫자 뒤에 \*\*`n`\*\*을 붙여 사용합니다 (`1000n`).
- **특징:** `Number`와 암시적 혼합 연산 시 \*\*`TypeError`\*\*를 발생시켜 정밀도 손실을 방지합니다.

#### 2.3. String 타입 및 유니코드

- 자바스크립트에서 문자열을 표현하기 위해 **UTF-16 인코딩**을 사용하며, 하나의 문자를 16비트로 표현합니다.
- **서로게이트 쌍 (Surrogate Pair):** 기본 다국어 평면(BMP)을 벗어나는 문자는 \*\*16비트 두 쌍 (총 32비트)\*\*으로 하나의 코드 포인트를 표현합니다.
  - **코드 포인트:** 유니코드에 정의된 문자의 **고유 ID** (추상적 값).
  - **코드 단위:** 코드 포인트를 저장하기 위한 **물리적 단위** (UTF-16은 16비트 단위).
- **템플릿 리터럴:** 백틱(\`)을 사용하며, 여러 줄을 적거나 표현식을 삽입할 수 있습니다. **태그드 템플릿** 기능으로 표현식으로 분리된 문자열을 받아 파싱하는 함수(태그)를 사용할 수 있습니다.

#### 2.4. Null과 Undefined

|       구분        |                                                                   Null (`null`)                                                                    |                          Undefined (`undefined`)                           |
| :---------------: | :------------------------------------------------------------------------------------------------------------------------------------------------: | :------------------------------------------------------------------------: |
|     **의미**      |                                                         **명시적**으로 값이 없음을 나타냄.                                                         |               **값이 할당되지 않음** (초기화되지 않은 상태).               |
|   **`typeof`**    |                                                              `"object"` (역사적 오류)                                                              |                               `"undefined"`                                |
|   **반환 상황**   |                                               `document.querySelector()`가 요소를 찾지 못했을 때 등.                                               | 변수 초깃값 누락, 속성이 없을 때, `return`에 값이 없을 때, `void` 사용 시. |
| **`void` 키워드** | 표현식의 결과를 **의도적으로 `undefined`로 강제 반환**하여, 인라인 `javascript:` URL 등에서 \*\*부작용(페이지 이동 등)\*\*을 방지하는 레거시 기술. |

### 3\. `Symbol` 원시 타입

`Symbol`은 객체 프로퍼티의 **충돌 없는 키** 생성을 목적으로 합니다.

- **생성:** `Symbol()` 함수로 생성하며, 호출될 때마다 \*\*고유하고 불변한 값(ID)\*\*을 생성합니다.
  ```javascript
  Symbol("a") === Symbol("a"); // false (유일성)
  ```
- **Description:** `Symbol.prototype.description`으로 조회 가능하며 디버깅 용도입니다.
- **Well-Known Symbols:** 자바스크립트 객체의 내부 동작을 재정의하기 위한 미리 정의된 정적 프로퍼티 (`Symbol.toPrimitive`, `Symbol.iterator` 등).
- **전역 공유:** \*\*`Symbol.for('key')`\*\*는 전역 Symbol 레지스트리를 통해 키를 공유하며, 같은 인자로 호출 시 \*\*`true`\*\*를 반환합니다.
- **은닉성:** `for...in`, `Object.keys()` 등 **일반적인 열거 메서드에 포함되지 않습니다.** (`Object.getOwnPropertySymbols()` 사용)

### 4\. `typeof` 연산자 예외와 래퍼 객체

#### 4.1. `typeof null`이 `"object"`인 이유 **(상세)**

- `typeof null` $\rightarrow$ `"object"`는 자바스크립트의 **초기 구현 버그**입니다.
- **근거:** 초기 자바스크립트에서는 값이 32비트 메모리에 저장될 때, \*\*객체를 나타내는 타입 태그는 `000`\*\*이었습니다. \*\*`null` 값은 `0x00000000`\*\*으로 정의되었는데, `null`의 하위 3비트가 객체의 타입 태그인 `000`과 **우연히 일치**했기 때문에 엔진이 `null`을 객체로 오인한 역사적 오류입니다.

#### 4.2. 래퍼 객체 (Wrapper Object)

`null`과 `undefined`를 제외한 원시 값은 프로퍼티/메서드 사용 시 **래퍼 객체**로 임시 변환됩니다.

- **명시적 래퍼 객체 생성:** `Object.prototype.valueOf.call(원시값)` 등을 통해 원시 값을 래퍼 객체로 감싸 `typeof` 결과가 `"object"`가 되게 할 수 있습니다.

<!-- end list -->

```javascript
const seven = Object.prototype.valueOf.call(7); // 원시값 7을 Number 래퍼 객체로 감쌈
console.log(typeof seven); // "object"
```

### 5\. 타입 변환 및 비교

#### 5.1. 암시적 vs. 명시적 타입 변환

- **암시적 타입 변환:** 평가 과정에서 자동으로 타입이 변환되어 평가됩니다.
- **명시적 타입 변환:** `toString`, `Boolean`, `Number` 등 개발자의 의도로 타입을 변환합니다.

#### 5.2. 객체의 원시 값 변환 규칙 (`Symbol.toPrimitive`)

객체를 원시 값으로 변환할 때(`ToPrimitive` 내부 메서드), 사용되는 **타입 힌트**에 따라 호출 순서가 달라집니다.

| 타입 힌트 (Hint) |            사용되는 컨텍스트             |                               호출 순서                               |
| :--------------: | :--------------------------------------: | :-------------------------------------------------------------------: |
|    `"number"`    |     `Number()` 함수, 단항 `+` 연산자     | `Symbol.toPrimitive` $\rightarrow$ `valueOf` $\rightarrow$ `toString` |
|    `"string"`    | `String()` 함수, `concat`, 템플릿 리터럴 | `Symbol.toPrimitive` $\rightarrow$ `toString` $\rightarrow$ `valueOf` |
|   `"default"`    |             이항 `+` 연산자              | `Symbol.toPrimitive` $\rightarrow$ `valueOf` $\rightarrow$ `toString` |

- **단항 `+`:** 피연산자를 `Number` 타입으로 강제 변환합니다.
- **단항 `-`:** 피연산자의 부호만 변경하며, `BigInt`에 사용 가능합니다. (BigInt는 `+` 사용 시 `TypeError`)

#### 5.3. Falsy와 Truthy

- **Falsy 값:** `undefined`, `null`, `0`, `-0`, `NaN`, `0n` (BigInt), `""` (빈 문자열) — 이중 NOT 연산자 (`!!`) 사용 시 `false`로 변환.
- **Truthy 값:** Falsy 값을 제외한 모든 값 (예: `"a"`, `1`, `[]`, `{}`) — `!!` 사용 시 `true`로 변환.

#### 5.4. 값과 타입의 비교

|      연산자       |                            동작 방식                            | `NaN` 처리 | `+0`, `-0` 처리 |
| :---------------: | :-------------------------------------------------------------: | :--------: | :-------------: |
|  **`==`** (동등)  |            타입이 다르면 **암시적 변환** 후 값 비교.            |  `false`   |     `true`      |
| **`===`** (일치)  |               **값과 타입** 모두 일치해야 `true`.               |  `false`   |     `true`      |
| **`Object.is()`** | 일치 연산자와 유사하나, `+0`/`-0`을 구분하고 `NaN`을 같게 취급. | **`true`** |   **`false`**   |

### 6\. 오버로딩과 오버라이딩

|    구분     |                                 Overloading (오버로딩)                                  |               Overriding (오버라이딩)                |
| :---------: | :-------------------------------------------------------------------------------------: | :--------------------------------------------------: |
|  **정의**   |              이름은 같으나 \*\*매개변수(개수/타입)\*\*가 다른 함수를 정의.              | **상속 관계**에서 부모 클래스의 메서드를 **재정의**. |
| **JS 지원** | 언어 차원에서 **지원하지 않음**. (함수가 마지막 정의로 덮어쓰여짐. 내부 분기 처리 필요) |  **지원함**. (클래스 상속 및 프로토타입 기반 상속)   |
